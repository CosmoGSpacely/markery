# References — monthly-image-review

Secondary sources relevant to this gallery project's scope: visual trademark
design in American manufacturing (1900–1939), with emphasis on industrial tool and
equipment companies and the administrative context in which marks were created,
filed, and managed.

## File format

## Cross-project retrieval need

The historian reviewing 1920s industrial trademarks — particularly marks filed by
manufacturers like Chicago Pneumatic Tool Company and Wilson Jones — would draw on
the information-systems references in addition to works held here.

**Specific passage needed from information-systems:** Galloway's "Card Index
Filing" section in
`information-systems/references/galloway-office-management.md` (pp. 153–154)
describes how manufacturers of this era tracked product and commercial
correspondence via card index systems. That passage provides direct context for
understanding *why* companies like Chicago Pneumatic filed and managed their
marks as they did — the marks in this gallery were created by organizations that
ran exactly the systematic filing departments Galloway documents. A historian
interpreting the design choices and filing dates of CP's trademarks cannot
separate those choices from the administrative culture that produced them.

This cross-project retrieval need is one concrete justification for the shared
`library/` directory built in Phase 15 P3: the same work serving both projects
should live in one place, not as duplicate files in each project's `references/`.
