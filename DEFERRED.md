| D007 | Implement `markery patent bulk-import` (PatentsView route) | **What it is:** An alternative patent acquisition path using USPTO's PatentsView bulk data (`.tsv.gz` files downloadable from patentsview.org) instead of the EPO OPS API. PatentsView covers all granted US patents since 1976 with rich metadata — assignee names, CPC classes, abstracts — in a single download. No API key, no rate limits, fully offline once downloaded. **Why deferred:** EPO OPS incremental fetch (current approach) has been sufficient. The EPO daily quota (~10k records) is restrictive but the build runs over multiple days without issue. PatentsView only covers 1976+, so it does not help with the pre-1940 scope of current projects. The bulk `.tsv.gz` files are large (~several GB uncompressed) and would need a separate download step outside the repo. **Design:** Complete in `src/markery/specialist/patent/BULK_CSV.md`. Command: `markery patent bulk-import --tsv-dir <path> --year-start <YEAR> --year-end <YEAR> --classes <CPC> [...]`. Implementation: DuckDB `read_csv()` with `delim='\t'`, predicate pushdown for year/class filter, `patent_no` constructed as `US{number}{kind}`, insert-if-not-exists (idempotent with current schema). **Reopen when:** (1) a project needs CPC classes outside the EPO OPS coverage window, or (2) EPO OPS quota becomes a genuine blocker for a time-sensitive sweep, or (3) a project with 1976+ scope is opened where PatentsView's coverage is sufficient. |
