# Content Schema: Sources Page

## Purpose

A consolidated bibliography of all primary and secondary sources used across the project. The sources page gives the research a citable foundation and allows readers to trace evidence back to its origin.

The sources page is a reference document, not a narrative. It does not argue; it lists. Its value is completeness and precision.

## Output file

`projects/<project>/content/sources.md`

## Structure

### Section 1: Primary sources — USPTO trademark filings

List all confirmed trademark serial numbers with their key metadata. This section is largely auto-generated from `confirmed.jsonl` but should be checked for completeness and annotation.

Format:
```
- **[Serial No]** [Mark name], [Filing date]. [Owner at filing]. 
  Goods: "[G&S description]". [Registration status].
  USPTO TSDR: https://tsdr.uspto.gov/#caseNumber=[serial]&caseType=US_APPLICATION&searchType=statusSearch
```

Cite the TSDR URL so readers can verify the filing record directly.

### Section 2: Primary sources — US patents

List all confirmed patent numbers with their key metadata.

Format:
```
- **[Patent No]** [Title]. [Assignee], [Grant date].
  CPC: [classes]. Google Patents: https://patents.google.com/patent/[US-number-A] (full doc id, e.g. US1389147A)
```

### Section 3: Secondary literature

Cite secondary works that ground the project's historical argument. Draw from `references/` directory files. Use Chicago author-date format consistently.

Format:
```
- Austrian, Geoffrey D. *Herman Hollerith: Forgotten Giant of Information Processing*. 
  Columbia University Press, 1982.

- Cortada, James W. *Before the Computer: IBM, NCR, Burroughs, and Remington Rand 
  and the Industry They Created, 1865–1956*. Princeton University Press, 1993.

- Yates, JoAnne. *Control Through Communication: The Rise of System in American 
  Management*. Johns Hopkins University Press, 1989.
```

### Section 4: Archival and institutional sources (if applicable)

Any physical archives, finding aids, or institutional collections consulted. Include location, collection name, and box/folder numbers where applicable.

### Section 5: Research method note

One paragraph describing the research method: that this project cross-references USPTO trademark filings against US patent records to identify patent-trademark correspondences for confirmed entities. State the data sources, the date range, and the CPC classes covered. This is not a disclaimer — it is documentation of method that allows another researcher to reproduce or extend the work.

## Output format

Plain Markdown. `##` section headings. Bulleted lists for sources within each section. No prose narrative except in the method note. Consistent citation format throughout (Chicago author-date for secondary literature; record-format for primary sources as specified above).

## Notes

The Sources section on individual match essay pages is generated by the site builder from the confirmed pair data. The `sources.md` page is the consolidated project-level bibliography, not a duplicate of per-page citations. Write it once and link to it from the landing page.
