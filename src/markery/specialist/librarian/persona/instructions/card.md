# Instruction Card: Librarian Card

## When to use

At the start of a historian session, to load relevant library passages as context. The card returns the top-matching passages for a query in a compact format (≤300 tokens), suitable for loading alongside a historian digest or candidate card.

## Command

```bash
markery librarian card "<query>" --mode semantic
markery librarian card "<query>" --mode keyword
markery librarian card "<query>" --top 5
```

Default mode is semantic if embeddings are available; keyword otherwise.

## Output

A compact block of 1–5 passages, each with work slug, page number, and excerpt text. Formatted for inclusion in a historian session context window.

## Notes

- **Semantic mode** requires `library/index.duckdb` with embeddings (generated by `markery librarian index --embed` with `sentence-transformers` installed). Falls back to keyword if embeddings are unavailable.
- **Keyword mode** works from `library/index.jsonl` alone — no embedding dependency.
- The card is the primary mechanism for delivering library context to historian sessions. Run it after `markery historian digest` and before beginning review.
- Token count for a card query is typically 150–300 prompt tokens. Rarely benchmarked separately — included in session totals.
